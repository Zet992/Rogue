# Rogue
2D Side Scrolling Shooter. The goal is to defeat a boss.

## Controls
**WASD** - Movement

**SPACE** - JUMP

**CONTROL** - Dash

**LEFT MOUSE BUTTON** - Shoot

**ESCAPE** - Show menu
